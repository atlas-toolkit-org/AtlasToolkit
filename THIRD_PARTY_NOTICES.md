# Third-party notices and licence audit

Atlas Toolkit is built on open-source work. The full licence texts ship inside the app in
`src/atlas_toolkit/licenses/`; the native helpers' notices there are regenerated by `native/build.py` from the
pinned sources. The app's About › Credits tab lists the same components.

## Libraries from the build system (Linux only)

The Linux build carries about 55 system libraries from its build image, AlmaLinux 9: X11 and xcb, GLib, FreeType, HarfBuzz, OpenSSL and others. `scripts/build.py` asks the image's package database for each one's package and licence, and writes them with their licence texts to `licenses/linux-system-libraries.txt` inside the build, so that list can't fall behind.

Most are MIT or BSD, and OpenSSL is Apache-2.0. These are LGPL: GLib, libgcrypt, libgpg-error, libblkid, libmount, and the library parts of systemd and keyutils. Some offer a choice, and D-Bus and graphite2 can be taken under AFL and LGPL respectively, not GPL. Item 6 below covers what that means.

## Libraries inside the Python packages

On every OS, the packages listed above bring native libraries of their own, in folders named `<package>.libs`. Most are permissive: OpenBLAS, GDAL, PROJ, HDF5, netCDF, libtiff, libpng, FreeType, HarfBuzz and others. These need more care:

| Library | Comes with | Licence |
|---|---|---|
| GEOS | Shapely, Rasterio | LGPL-2.1 |
| libgfortran, libgomp (Linux) | NumPy, SciPy, fast-simplification | GPL-3.0 with the GCC runtime library exception |
| libquadmath (Linux) | NumPy, SciPy | LGPL-2.1 |
| iconv (Windows) | Rasterio | LGPL |
| SpatiaLite, FreeXL (Windows) | Rasterio | A choice of MPL, GPL or LGPL |

Windows builds also carry Microsoft's redistributable C++ runtime (`msvcp140`, `vcruntime140`) and Universal CRT (`ucrtbase`, `api-ms-win-*`).

## Installer tools

Each of these leaves a small piece of itself in the installer: the Inno Setup installer and uninstaller (Inno Setup's own licence, which permits commercial use), and the AppImage runtime (MIT). nfpm and dmgbuild leave nothing behind.

## Installed separately, never shipped

Blender (GPL-3.0-or-later), PyTorch (BSD-3-Clause), Hugging Face Transformers (Apache-2.0), and the depth
models. The depth environment's installer (Setup › Components) downloads these on the user's request, with uv
(MIT OR Apache-2.0, from Astral's GitHub releases, checked by SHA-256) and a standalone Python, also pinned and checked
(python-build-standalone: the PSF licence and those of its bundled libraries). None of them is part of the app or its
installers. MiDaS 3.1 BEiT-L-512 is MIT and DPT-Large is Apache-2.0. **Depth Anything V2 Large is for non-commercial use
only** (CC BY-NC 4.0).

## Compliance

Atlas Toolkit itself is GPL-3.0-or-later (`LICENSE`, `COPYRIGHT.md`). Every component above may ship with it.

1. **The developable helper is GPL-2.0-or-later.** Its upstream files say "version 2 of the License, or (at your
   option) any later version". It is a separate program: the app only starts it as a subprocess and exchanges files
   with it.
   - Every distribution includes its complete corresponding source. `native/build.py` writes
     `developable-source.zip`, and `scripts/build.py` publishes it next to the exe.
   - The GPL text and the helper's notices ship as well. `scripts/audit_bundle.py` fails a build without them.
2. **libigl** is MPL-2.0 for the headers the developable helper uses. None of its GPL modules are compiled in;
   recheck this if the helper's includes change.
   - The libigl Python wheel also carries modules under other licences: `igl.copyleft` (CGAL, GPL-3.0; TetGen,
     AGPL-3.0) and `igl.triangle` (Shewchuk's Triangle, which is not open source and may not be redistributed in
     products).
   - Atlas imports none of them, and `packaging/atlas_toolkit.spec` leaves them out of every bundle.
     `scripts/audit_bundle.py` fails a build that contains them.
3. **LGPL components** (PySide6/Qt, GEOS, libquadmath, iconv, and the Linux system libraries above):
   - The folder builds and the installers load them from separate files that users can replace.
   - The single Windows exe packs them inside. Because the app's complete source is public under the GPL, users can
     still rebuild it with other versions of those libraries.
   - Their licence texts ship. The Linux system libraries' source is published by AlmaLinux (see
     `licenses/linux-system-libraries.txt`).
4. **The research reproductions** (FlowRep, stripe extraction) are independent implementations. The FlowRep
   authors' models and networks are not redistributed.
5. **Depth Anything V2 Large** is CC BY-NC. Atlas never ships it. Setup marks it non-commercial, and the default
   model is MiDaS (MIT).
6. **Still to check one by one:** the notices of the native libraries inside the Python wheels (the `<package>.libs`
   folders, listed above). Have someone who knows these licences confirm that every text ships.
